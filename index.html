Expense Tracker

1. Introduction

Expense Tracker is a personal expense and income tracking application designed to help users record and manage their financial transactions on their device.

This Privacy Policy explains what information the application stores and how that information is handled.

2. Information Stored by the App

Expense Tracker allows users to enter and store:

  • Transaction amount
  • Transaction type (expense or income)
  • Category
  • Date
  • Note
  • Payment method
  • Custom categories
  • Custom payment methods

The application also stores the selected application theme preference, such as light, dark, or system theme.

3. Where Your Data Is Stored

Your transaction and application data is stored locally on your device using local database and application storage.

The current version of Expense Tracker does not provide:

  • User accounts
  • Login or registration
  • Cloud synchronization
  • A remote database
  • A developer-operated backend for transaction data

The current version does not transmit your transaction data off your device to the developer or to third-party services.

4. Data Collection and Sharing

The current version of Expense Tracker does not contain application functionality for:

  • Advertising
  • Analytics
  • Firebase services
  • Crash-reporting services
  • Social-media tracking
  • Third-party transaction tracking
  • Selling user information
  • Sharing transaction information with third parties

The application does not intentionally transmit your recorded transactions to the developer or another company.

5. Device Permissions

The current Android release does not request permissions for:

  • Camera
  • Microphone
  • Location
  • Contacts
  • SMS
  • Phone calls
  • Photos or media
  • Internet access

The application uses standard Android application components required to run the app.

6. Deleting Your Data

Expense Tracker provides functionality to delete individual transactions.

The Settings section also provides an option to delete all transactions.

Deleting all transactions permanently removes the transaction records stored by the application.

Categories and application settings are not deleted when using the “Delete all transactions” option.

7. Data Security

Because transaction data is stored locally on your device, protecting access to your device is important.

The application does not currently provide a separate account or password system for protecting the stored transaction database.

8. Children's Privacy

Expense Tracker is a general-purpose personal finance record-keeping application.

The current version does not provide an online account or data-collection service.

9. Changes to This Privacy Policy

This Privacy Policy may be updated if the application's functionality or data practices change.

Any updated version will include a revised effective date.
